# Orbyx HRMS - Backend Service

This directory contains the backend service structure for the Orbyx HRMS application.

## Directory Structure

- src/config/: Configuration setup (database, environment, auth).
- src/controllers/: Request handlers for HRMS domain entities.
- src/services/: Core business logic and rules.
- src/routes/: API endpoint definitions.
- src/middleware/: Authentication, RBAC, request validation and error handlers.
- src/models/: Domain data models and entities.
- src/utils/: Shared utilities, formatters and helpers.
- database/migrations/: Database schema versioning migrations.
- database/seeds/: Initial master data and demo seeding scripts.
